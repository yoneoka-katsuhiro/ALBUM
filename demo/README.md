# Synthetic demonstration / 合成デモ

The two JPEG files contain identical synthetic artwork generated by `scripts/smoke_test.py`, with a capture time of 2026-01-02 09:00:05 +09:00. They are not camera photographs. The GPX has two artificial points ten seconds apart. Neither represents a measured location or route.

To try the standalone application from its extracted folder:

```bash
./album --project-dir demo --photographer demo --location field --geotag --gps-timezone +09:00
```

On Windows, replace `./album` with `.\album.exe`. The first run should copy one image, skip one duplicate, and add 35.001° latitude / 139.001° longitude to the output. The second run should copy zero images and skip two duplicates. Outputs are written to `demo/output`; input bytes stay unchanged.

2枚のJPEGは同一の合成画像です。撮影画像・観測値ではありません。初回はコピー1件・重複1件・GPS付与1件、再実行はコピー0件・重複2件になります。写真を変更していないことを試せます。データのライセンスはALBUMと同じMITです。
